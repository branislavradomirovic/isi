# ADR-0018 — ORDO Domain Foundation

## Decision
ORDO is implemented as an independent domain model under the shared ISI platform core. It shares identity, tenancy, data ingestion, AI orchestration and audit infrastructure, but it does not share SIMPA domain tables, indicators or semantics.

The ORDO foundation models destination development as an interconnected system of resources, heritage, people, economy, infrastructure, knowledge, entrepreneurship, identity and community. ISI-10 records domain structure and provenance only. Analytical scoring, scenario logic and AI-assisted synthesis belong to ISI-11.

All initial indicator entries are conceptual registry items. They are not validated methodologies and must not be treated as computed destination scores.
